# DMS / OMS / In-Cabin Sensor Master Reference

This reference intentionally separates:

- Premium automotive DMS/OMS sensors
- Cost-sensitive automotive DMS sensors
- Automotive and near-production alternatives
- Industrial global-shutter prototype sensors
- Low-cost rolling-shutter prototype cameras
- DIY cameras suitable only for software bring-up

The fit scores are **ADVIS engineering comparison scores**, not manufacturer ratings. Public sensor pricing is rarely available for automotive parts, so publicly observed **module/listing prices** are kept separate from RFQ-only sensor cost.

## Interpretation

- **Production fit 5:** credible automotive DMS/OMS path with qualification/safety/lifecycle potential.
- **Prototype fit 5:** readily usable and affordable module ecosystem, not necessarily automotive.
- **Global shutter + strong 940 nm NIR** remains the preferred focused-DMS architecture.
- **RGB-IR** becomes more valuable when the scope expands from driver monitoring to occupant/cabin context.
- **5 MP** is justified for whole-cabin OMS, child presence and multiple-row coverage; it is usually unnecessary for cost-first driver-only DMS.
